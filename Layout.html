🔧 Umsetzung - So funktioniert es:

1. Daten kommen aus Supabase
Tabelle stammdaten • Feld marketing JSONB enthält EN/TL/DE
Bild URLs: bild_sack_url + bild_reis_url echte https:// links
2. Dropdown füllt Layouts
JS: supabase.from('stammdaten').select('*') -> füllt Select
Bei Auswahl: alle 4 Layouts werden mit artikel.marketing[lang] befüllt
3. Facebook Ready Export
Button "PNG Export" nutzt html2canvas -> 1080px PNG
Direkt hochladen zu Facebook Page / Ads Manager. Kein Photoshop nötig.
